// Как перевести центральную звезду на рельсы ЭРТХ, при условии, что эта звезда последняя и над ней уже ничего нет?  
// Инструкция на примере D-Link DGS-3000-28sc  

1) Создаём 99 VLAN, называем его MGMT и закидываем в него все нужные порты.  

create vlan vlanid 99 name MGMT  
config vlan vlanid 99 add tagged 1,5,7-8,10-12,14-15,17-19,21-27  
show vlan vlanid 99  

2) Накидываем на этот VLAN IP-шник из нужной подсети.  

config ipif System vlan MGMT ipaddress 10.245.151.xx/26 state enable  
// После этого заходим на коммут уже через PUTTY, по новому IP и проверяем, что связь с ним есть.  

3) Когда зашли через Путти, накидываем новый шлюз. Сначала накинем новый шлюз, старый удалим чуть позже...  

create iproute default 10.245.151.62 1  
// 1 - это метрика, а не номер порта. Её желательно указывать.  
// 62 - это конкретный gateway, он высчитывается от маски подсети.  

4) Путём таких манипуляций, мы подменим дефолтный gateway своим, НЕ ПОТЕРЯВ текущую сессию.  
Теперь удалим старый шлюз.  

delete iproute default 10.140.0.1  

// Проверим, что получилось.  

show switch  
show iproute

| 10.245.151.0/26    | 0.0.0.0       | System    | 1    | Local    |  

// Везде должен светиться новый ЭРТХ-шный шлюз: 10.245.151.хх (в нашем случае 10.245.151.62)  

5) Сохраняемся!  

save
