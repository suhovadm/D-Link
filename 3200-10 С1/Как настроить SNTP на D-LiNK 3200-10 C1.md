// Как настроить SNTP на D-LiNK 3200-10 C1 ?  
// SNTP - упрощённый протокол NTP (протокол синхрона времени на сетевых железках).  

enable sntp  
config time_zone operator + hour 7 min 0  
config sntp primary 10.6.37.21 secondary 10.6.36.38 poll-interval 3600  
save  

// Таким образом, мы устанавливаем сдвиг на 7 часов и 0 минут.  
// Команда operator говорит о том, что настройки проводятся вручную.  
// Как проверить?  
// Вводим show time на коммутаторе и смотрим время.  
// Затем, гуглим реальное время. Время должно совпадать.  
// Сохраняемся командой save.
